RINSORA LAB

小窝设置

主题会一起换掉背景、极光、玻璃卡片、按钮、导航、歌词高亮与项目标签 —— 不只是变个底色。

色相只作用在背景场景层，不会污染文字与按钮的配色。

夜间模式快速在日间 / 夜间之间切换
星尘粒子背景里漂浮的小光点（Canvas，不是一堆 DOM）
极光光晕背景里缓慢游动的几团色雾
装饰元素网格地面、噪点、漂浮的小星星
鼠标光晕光圈会追着你的指针（仅桌面）
卡片倾斜悬停时产生轻微 3D 反光
点击涟漪点击时留下一圈水波和几颗小心心

在系统里开启「减少动态效果」时，这些会自动降级成静态，不会强行播放。

VERSIONRinsora Home V3

把小窝从「几个页面」变成一个连续的空间：统一的状态机与转场、五套可换的主题引擎、分层动态背景、极坐标扇形导航、时间线与更稳的播放器。

DESIGNCandy / Macaron / Acrylic
STACKHTML · CSS · 原生 JavaScript
HOSTGitHub Pages（无构建）
THEMEScandy · sunset · lavender · mint · night

所有偏好（主题、色相、特效开关）只存在你自己的浏览器里，不会写进仓库。

快捷键：1~4 切分栏 · Ctrl/⌘ + K 开设置 · Esc 收起一切

changes are saved locally ♡
