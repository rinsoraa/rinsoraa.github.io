为什么我想做一个属于自己的小窝

2026.09.21 空凛 / Rinsora 约 3 分钟

“想有个自己的主页”这件事，在我脑子里放了很久。不是没有可以写东西的地方，而是总觉得那些地方少了点什么。

现成的平台，和不够用的地方

用现成的博客平台当然更省事：注册、选模板、发文章，十分钟就能开始写。但很快就会发现两件事——

  • 模板感太强。别人的框架决定了你的样子，改到后面总有一种“在出租屋里贴海报”的感觉。
  • 节奏是别人的。推荐流、点赞、评论，都在推着你写“别人想看的东西”，而不是你想留下的东西。

而我想要的其实很简单：一个可以慢慢往里加东西的地方。今天加一个音乐播放器，明天换一张头像，后天把某个奇怪的小实验挂上去——没有人在旁边催。

为什么选了纯静态 + GitHub Pages

技术上我没有犹豫太久。纯静态页面 + GitHub Pages 的组合，几乎正好对上了我的需求：

  • 不要服务器。没有后端就没有要维护的东西，不会半夜因为证书过期或者内存泄漏爬起来。
  • 文件即全部。整个站点就是几个 HTML / CSS / JS 文件，本地双击就能打开，改坏了直接改回来。
  • 有版本历史。每一次改动都有记录，比任何云笔记的“历史版本”都踏实。

记录一些喜欢的东西，也记录正在成为的自己。

它现在还不完整

目前这里只有三个板块，文章也没几篇，音乐还是临时凑的。但我觉得这样挺好——一个站点应该是一点点长大的，而不是一次性搭完就再也不动。

所以我打算慢慢来：以后会把折腾过的项目、踩过的坑、偶尔冒出来的想法都放进来。如果你恰好路过，欢迎随便逛逛 ♡
