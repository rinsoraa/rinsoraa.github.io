给音乐博物馆写回归装置：抓那些「看着对、其实没生效」的 bug

2026.09.24 空凛 / Rinsora 约 7 分钟

音乐博物馆这个板块做到第八轮，我已经不太相信自己的眼睛了——太多 bug 是「看着对、实际上根本没生效」的：类名、DOM、数据全都对，但功能就是不动。这种 bug 没有报错、没有堆栈，只能靠一套自动化的回归装置把它们一个个逼出来。

这套装置现在是一行命令跑完：python _mm3all.py，五件套共 1685 条断言，全绿。写下这篇，是想把这段时间踩过的几类坑和它们的解法记下来，省得以后重蹈覆辙。

一、「看着对、其实没生效」的三兄弟

第一类最阴，我给它起了个名字叫「inline 压死样式表」。

唱片的基础缩放由 JS 按「离焦点的距离」算出来，写成内联样式 --mm-scale。然后我想让 hover、选中的时候再放大一点，就在 CSS 里写了 .mm-disc:hover{--mm-scale:calc(...)}。结果 hover 完全没反应，而类名、DOM、computed 值全都对。

根因是：内联样式的优先级高于样式表，JS 写的那个同名变量把 CSS 里的覆盖规则「压死」了。解法是把变量拆两层——--mm-scale-data（内联，给底值）+ --mm-scale:var(--mm-scale-data,1)（样式表默认，状态规则只覆盖它）。这个坑后来在 z-index 上又原样复现了一次，只是换了个属性名。

第二类是「声明了，但没进属性」。写过 --depth-x 却忘了把它拼进 transform，结果是五张唱片位移完全一致——功能看着有，其实每一张都在原地。

第三类更气人：代数恒等不是修复。(a-1)*-0.6 和 (1-a)*0.6 是同一个数，换了写法等于没改。我调「方向符号」调了半天，数值一个都没动。

二、「第二真相」：一条状态只能有一个落点

好几次 bug 的根子是同一个：同一件事被存了两份，两份会慢慢漂移。

比如播放按钮的「在播 / 暂停」这个 bit，一度同时存在 is-playing 和 data-state 两个地方。再比如歌词高亮：博物馆选中的唱片，和播放器正在播的唱片，是两件事——如果你去读播放器内部的 active 状态，就写了一份「第二真相」，选中的歌没在播时歌词会假装在播。

现在的铁律是：一条状态只有一个落点，而且别去读别人的内部状态当真相。

三、改「派生值」之前，先问一句「谁反写它」

「进厅认出正在播的那首」这个需求，第一版只在 enter() 里写了 selectedIndex。但 selectedIndex 是个派生值，它会从 fanTo 反写回来——于是紧接着那次同步，用上一次残留的 fanTo 把它又改了回去。

症状是：首次进厅正常，第二次进厅焦点停在上一张。修法是把 selectedIndex / fanTo / fanPos 三件一起写。教训：动一个派生值之前，先搞清楚谁在反写它。

四、回归装置自己也会骗人

写完测试不等于安全。这套装置自己就出过三种「假红」，还有一种更危险的「假绿」。

假红最好查——一般是断言写错了，或者设计变了旧期望没跟上。值得警惕的是假绿：有一条断言是靠「强行给对象安一个假属性」才通过的，它其实在替一个真 bug 打掩护。那次是滚轮让位的目标，我给它 stub 了 scrollHeight 才绿，实际上那个容器从来就不能滚动。

教训写成了两条：期望值要从数据推导，别硬写条数；每条断言的前置状态要自己造，别继承上一个用例的残留。

五、无头浏览器挂了，jsdom 顶上

本机的无头 Edge 突然「死了」——启动返回 0，但什么都不干，连 --version 都零输出。真截图这条路断了，我改用 jsdom 承担逻辑与结构验证。

jsdom 有六条必踩的坑：脚本要 runScripts:'dangerously' 才会执行；clientWidth 恒为 0，任何按视口分支的逻辑都会走窄屏那条；setInterval 会让进程永不结束，得手动 close() + exit()……但这些都比不上「浏览器真机目视」——像素、配色、动画观感，jsdom 一个都验不了。

六、性能上的静默 bug（这轮刚修的）

第八轮上线后，滚轮切歌时唱片会短暂闪没。查下来是两件事叠在一起：焦点唱片上的提示条嵌在带 filter 的唱片里，又用了 backdrop-filter，每次换焦点改它的文字，都会连累整张唱片重新光栅化；再加上歌词面板每次换歌都读一次 clientHeight，强制了一次同步布局。

修法很朴素：去掉那个不必要的 backdrop-filter，把歌词取景框的尺寸缓存起来，只在真正变化时才重读。

小结

原生 JS 的静态站，最可怕的不是报错，是静默失效。报错至少告诉你哪里错了；静默失效只会让你在 CSS 里调半天数值，然后怀疑人生。所以我把这段时间的每一类坑都沉淀成了断言——不是因为我喜欢写测试，是因为我实在不想再被同一类 bug 骗第二次。
